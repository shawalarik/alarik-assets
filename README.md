# Alarik Assets 图床项目

本仓库用于存放各类静态图片资源的图床服务。

## 目录结构

| 目录 | 说明 |
|------|------|
| `avatar/` | 头像（个人/作者/评论头像） |
| `banner/` | 首页大图、轮播、站点头图 |
| `post/` | 文章插图（按年月或主题再分子目录） |
| `friend-link/` | 友链头像/封面 |
| `gallery/` | "你"个人喜欢图库（推荐单独拆出） |
| `cover/` | 文章封面（和正文插图分离，便于管理） |
| `logo/` | 站点 logo / favicon / 品牌图 |
| `social/` | 社交分享图、OG 图（微信/推特卡片） |
| `temp/` | 临时素材（定期清理） |
| `archive/` | 历史旧图（避免误删） |

## 使用规范

1. 上传前请确认正确的目标目录
2. 文件命名尽量清晰有意义（建议英文+数字+短横线）
3. `temp/` 目录定期清理
4. `archive/` 目录谨慎操作
